# Workflows

This directory contains the python files with the workflows for the SUEP muon search. There are workflows for each one of the regions, as well as for independent studies.

## CMS Corrections

Additional corrections for CMS analyses are stored in the CMS_corrections directory and can be called directly in the main workflows.

The following corrections/uncertainties are applied in the main workflows:

- Golden JSON
- JECs
- Parton Shower
- Prefire
- Lepton SF
- Pileup Weight
- Track killing
- Higgs pT reweight
